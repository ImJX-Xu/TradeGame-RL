# PPO 第一版方案

本文档记录 TradeGame-RL 当前第一版强化学习方案，作为后续方案比较的固定基线。

## 1. 游戏与智能体接口

游戏核心由 `trade_game.core` 独立维护，负责状态、价格函数、交易、运输、融资、车辆、时间推进和终局结算。智能体通过 `AgentEnvironment` 访问游戏，环境内部仍然调用 `GameSession.dispatch` 执行核心命令。

智能体动作采用六元组：

```text
(action_index, product_index, city_index, transport_index, quantity_index, fast_index)
```

`action_index` 直接选择八类操作：买入、卖出、旅行、借款、还款、修车、买货车和推进日期。商品、城市和运输方式使用当前目录的稳定索引；数量使用 21 档：`1`、`5%` 至 `100%`；`fast_index` 选择普通或快速运输。

动作掩码在策略采样前应用。第一层掩码限制八类操作，条件掩码再限制商品、城市、运输方式和数量档位，最终动作由动作解码器转换为核心 `Command`。

## 2. 状态编码

状态观测保持为结构化对象，之后由 `ObservationBatch` 转换为 PyTorch 张量。当前市场行情使用城市 x 商品 x 四日历史矩阵，时间点为：

```text
D-6, D-4, D-2, D
```

商品、城市、区域、商品类别和运输方式使用 embedding；价格使用相对商品基础采购价的对数比值。编码器分别处理城市、商品、全局经营状态、市场行情、路线和货物批次，再通过注意力聚合市场、路线与货物实体，输出固定维度状态向量。

第一版默认编码配置为：

```text
embedding_dim = 16
entity_dim    = 64
state_dim     = 128
hidden_dim    = 128
```

## 3. 策略与价值网络

网络采用共享状态编码器的 Actor-Critic 结构。策略部分按动作实际需要组织条件分支：

- 动作类型头：八类核心操作；
- 买入/卖出商品头；
- 旅行城市头、运输方式头和快速运输头；
- 买入、卖出、借款、还款和购车数量头。

各条件分支只在对应动作被选中时参与联合动作概率。PPO 使用完整六元组的联合 `log_prob`，而不是把每个动作头拆成相互独立的 PPO 目标。

价值网络使用同一状态编码器，输出全局状态价值 `V(s)`。

## 4. 奖励与 PPO

第一版使用 `reward_v1`：

- 以可清算资产的对数增量作为密集奖励；
- 终局根据最终资产提供终局奖励；
- 破产提供惩罚；
- GAE 和 bootstrap 按实际经过天数使用 `gamma ** elapsed_days` 折扣。

PPO 使用原生 PyTorch 实现，包含：

- rollout buffer 与结构化轨迹；
- 动作掩码下的联合 log probability；
- clipped policy objective；
- clipped value objective；
- 熵正则、KL 目标、梯度裁剪；
- 固定种子确定性评估。

1M 步基线训练使用 `1,954` 次更新、每次 `512` 个环境决策，共 `1,000,448` 步。主要配置为：

```text
gamma              = 0.995
gae_lambda         = 0.95
ppo_epochs         = 4
minibatch_size     = 64
learning_rate      = 3e-4
clip_range         = 0.2
value_clip_range   = 0.2
entropy_coefficient = 0.01
target_kl          = 0.03
```

## 6. 第一版结果

最终检查点为：

```text
runs/ppo_1m_diagnostics/ppo_1m.pt
```

在固定种子 `101、103、107、109、113` 上的最终资产为：

| 种子 | 最终资产 |
|---:|---:|
| 101 | 88,414.88 |
| 103 | 1,387,997.22 |
| 107 | 5,245,861.48 |
| 109 | 234,804.93 |
| 113 | 3,625,638.39 |

五个种子的平均最终资产为 `2,116,543.38`，中位数为 `1,387,997.22`，破产率为 `0`。最高收益种子在第 107 局达到 `5,245,861.48`；策略首次在训练过程中超过平均资产 100 万约发生在 `261k` 步。

## 7. 第一版行为特征

第一版策略已经形成交易、运输、融资和扩容闭环，能够持续借款并购买货车。在高收益种子中，策略会反复借入可用额度的约 `90%`，购买多辆货车，并在石家庄与北京之间运输高价值商品，形成资产正反馈。

当前策略的主要特征是高杠杆和低还款倾向：收益路径顺利时会快速扩大库存与运力，行情路径不利时则会因为债务、运输成本和错误路线产生较大回撤。五个评估种子的总体标准差约为 `2,012,710.80`，最大收益约为最小收益的 `59` 倍，说明第一版已经具备有效盈利能力，但收益分布仍然高度离散。

第一版因此作为后续方案的性能与行为基线：后续方案需要在保持高收益能力的同时，单独比较收益均值、中位数、尾部风险、杠杆使用、还款行为和跨种子稳定性。
