# 智能体结构

当前智能体由结构化状态编码、条件离散策略、全局价值估计和原生 PPO 训练闭环组成。以下文档按数据与计算顺序组织：

1. [状态编码器](state-encoder.md)：将城市、商品、四日行情、路线和货物批次编码为固定维度状态。
2. [Actor-Critic 条件动作网络](actor-critic.md)：生成条件动作分支、联合动作概率与价值估计。
3. [原生 PPO 训练流程](ppo-training.md)：描述采样、GAE、裁剪目标、参数更新和指标记录。
